# 方法与实现

本项目保留 Gaussian 初始压力场、可微光声前向以及基于 RF 误差优化点参数的框架。它在初值、前向计算、正则和密度调整上采用特定设计，应称为 SlingBAG 思路下的变体。`configs/pose000.json` 是已选定的单帧流程，整理成独立仓库没有重新搜索超参数。

## 表示与连续前向

每球有中心 `μ_i=(x_i,y_i,z_i)`、非负峰值 `P_i`、标准差 `σ_i`，初始压力场为

```text
p0(x) = Σ_i P_i exp(−||x−μ_i||² / (2 σ_i²)).
```

实测探头位置为 `s`，实现的光声预测为

```text
r_i = sqrt(||s−μ_i||² + 1e−12)
p(s,t) = Σ_i P_i (r_i−ct) / (2 r_i) × exp(−(r_i−ct)² / (2 σ_i²)).
```

附带 pose000 配置采用 `c=1500 m/s`、`t=n×25 ns`、4096 个采样点。新数据的声速、采样频率和时间长度由配置经过数据准备 metadata 统一传给训练与导出，`t=n/fs`。CUDA 使用 FP32、±6σ 截断。它参考 PA-SfM-NC 的连续解析形式，直接在采样时间求值，替代原来的 10 层同心均匀球近似，不经过固定 σ 的 KDE 插值。`rapid_forward.gaussian_reference` 提供可用于 CPU/FP64 核验的 PyTorch 实现。

Gaussian 体素导出直接计算压力场叠加，体积为 `400³`、0.1 mm。CUDA 数值与 FP64 参考存在舍入及截断差异；训练加速不等于任意情况下数学上完全无误差。

## 随机初值与坐标更新

初始一百万个中心由 seed=1013 在 XYZ 各 ±20 mm 范围内 IID 均匀采样；压力用独立 RNG seed=1014 在 `[2,6]` 均匀采样；所有初始 σ 为 0.25 mm。初始化不读取 RF 强度、DAS、PA 体积、掩膜或历史点云。

优化器先只更新压力，然后允许 XYZ 更新。位置参数以 0.1 mm 为数值单位，`xyz=anchor+offset×0.1 mm`；Adam 在连续浮点坐标上按梯度更新，没有将中心四舍五入到体素中心。每阶段位移范数限制和视野裁剪属于投影约束，边界处不能解释为全局光滑操作。

训练阶段内 σ 固定。前向实现本身提供 σ 梯度，但当前训练配置并未用 Adam 联合更新每球 σ。球分裂、宽度缩小、非负投影和检查点选择也是离散或分段操作。

## 物理场正则与优化

损失为归一化 RF MSE 加物理场先验和弱稀疏项：

```text
loss = mean((prediction−RF)²) / mean(training_RF²)
       + λ × (isotropic_TV(field) + 2 × Hessian_curvature(field))
       + 0.02 × mean(field)/100.
```

空间项在实现中以 0.1 mm 为差分参考间距、100 为幅度尺度。TV＋Hessian 曲率不等同于严格的 TGV，也没有把参考重建图像作为目标。

先验场使用质量沉积的 cloud-in-cell（CIC）和可分离 Gaussian 平滑近似。CIC 对邻域权重分段可微，所有球都参与沉积；网格并不限制球心位置。平滑方差减去平均 CIC 方差 `spacing²/6`，要求 `σ>spacing/√6`。这只补偿平均二阶矩，不是精确的逐点 Gaussian 求和。开放 XYZ 更新后会停止使用固定位置的沉积缓存。

使用 Adam，ε=1e−10，压力参数为 `P/100`；学习率在各阶段余弦衰减至初值的 20%。896 探头训练阶段随机分批，每批 128。阶段内部保留优化器状态，阶段切换重新创建优化器。

## 细分和变窄

coarse 阶段后按照本模型学习到的 `Pσ³` 选择 60,000 个可在视野内细分的父球。每个父球由 8 个子球替代，σ 比例 `q=0.6`：

```text
σ_child = q σ_parent
μ_child = μ_parent + (±1,±1,±1) σ_parent sqrt(1−q²)
P_child = P_parent / (8 q³).
```

此步骤保持总积分质量、质心和完整协方差张量，不保证更高阶矩、逐点场或 RF 不变。候选数由 1,000,000 变为 1,420,000。它替代了原 SlingBAG 的梯度触发复制/删除规则。

fine 阶段以后，把 σ<0.20 mm 的球改为 σ=0.10 mm，通过 `P_new=P_old(σ_old/σ_new)³` 保持每球质量和位置。这个步骤改变协方差、体积场和预测 RF，因此作为新提案在 step 0 重新评估。导出时只删除压力精确为零的球，没有另加显示阈值。

## 响应校准与最终分支

窄球模型先在 896 探头上拟合 41 tap 的共享 FIR，128 保留探头从预设 ridge 候选选择响应。历史实验选择 ridge=10；继续用该响应更新点参数的 200 步诊断没有改善保留探头 MSE，选择了该阶段 step 0。

最终分支从变窄后的初始模型重新开始，以固定 500 步在全部 1024 探头上更新点参数，训练时不使用 FIR。随后固定 ridge=10，用全部探头拟合最终经验 FIR。它是先点优化、后 RF 校准；不声称联合优化或识别出唯一真实硬件响应。经验 FIR 不改变测量信号、点云或体积。

完整复现入口保留响应诊断分支以反映选择过程。最终分支始终使用既定策略，不会根据新一轮短 smoke 的验证偶然结果自动改写科学协议。

## 与原 SlingBAG 的关系

| 方面 | 本项目 |
|---|---|
| 表示 | 保留 Gaussian 球心、峰值与尺度表示 |
| RF 前向 | 连续解析 Gaussian CUDA，替代十层离散球 |
| 位置 | 连续可微更新，分阶段 warmup 和位移约束 |
| 尺度 | 每阶段固定，阶段间守恒细分/质量保持变窄 |
| 正则 | 加入完整近似压力场 TV＋曲率和弱稀疏项 |
| 数量调整 | 受控的守恒 8 子球细分 |
| 最终 RF | 点训练后增加共享经验响应校准 |

因此这个仓库同时包含前向加速和算法调整。结果适用范围、验证子集用途和尚存的结构差距见 [RESULTS.md](RESULTS.md)。
